# Червяки — 2D-артиллерия в духе Worms (Unity)

Пошаговый бой команд на разрушаемом ландшафте: остров, пещера, архипелаг, каньон
или снежные холмы. Весь мир — ландшафт, спрайты, украшения, звук и интерфейс —
генерируется из кода: в проекте нет ни одного бинарного ассета.

Подробности реализации — в [docs/DESIGN.md](docs/DESIGN.md), история работы —
в [docs/HISTORY.md](docs/HISTORY.md).

## Запуск

Игра открывается в главном меню: **Хотсит** — бой двух команд за одним
устройством, **Настройка матча** — число команд и червей, время хода, тип мира,
боезапас, **Быстрый бой против бота** — то же против компьютера. Если сцена не
открылась — меню **Worms → Создать игровую сцену**.

## Управление

Схема выбирается сама: взяли геймпад — переключились на него, коснулись
экрана — на касания. Подсказка внизу меняется вместе со схемой.

| Действие | Клавиатура | Геймпад | Касания |
|---|---|---|---|
| идти | ← / → (A / D) | левый стик вбок | кольцо стика слева |
| угол прицела | ↑ / ↓ (W / S) | левый стик вверх-вниз | кнопки ▲▼ справа |
| прыжок | Enter (J) | A | рывок стика вверх, кнопка «прыжок» |
| выстрел | Space — держать, отпустить | X | «ОГОНЬ» или потянуть от червя |
| выбор оружия | 1–9, 0; Q / E — листать | бамперы | сетка оружия внизу |
| сменить червя | Tab | Y | кнопка → рядом с паузой |
| камера | колесо — зум, средняя — панорама | триггеры, правый стик | щипок и ведение |
| пауза | R / Esc | Start | кнопка ❚❚ |

На верёвке те же органы значат другое: вбок — раскачка, вверх-вниз — длина,
прыжок — отцепиться.

Ракета, налёт, телепорт и прочее «по метке» наводятся крестиком, а не стволом:
его ведут стиком или ставят тычком по экрану, «Огонь» ставит метку, и только
потом идёт обычный выстрел. Пока цель не отмечена, вместо таймера горит
«отметь цель». Смена оружия наводку отменяет.

## Правила

- 2–4 команды по 1–8 червей, ход по умолчанию 40 секунд. После выстрела ход
  завершается, даётся ~3 секунды на отход.
- В начале хода ход можно передать другому своему червю — до первого действия.
- Ветер меняется каждый ход и сносит базуку и кассету (гранаты — нет).
- Падение в воду убивает мгновенно, падение с высоты калечит. Погибший червь
  взрывается сам.
- С неба падают ящики: аптечка на 25 здоровья или два патрона к случайному
  оружию. Взрыв рядом ящик детонирует.
- С восьмого раунда — внезапная смерть: у всех по единице здоровья, вода
  прибывает на 1,3 юнита за раунд.
- На архипелаге и в каньоне переброшены подвесные мосты: по ним ходят, их рвёт
  взрывом вместе с землёй.
- Побеждает команда, у которой остался хотя бы один живой червь.

## Оружие

28 пунктов, собранных по оригинальным «Червям».

| Группа | Пункты |
|---|---|
| Баллистика | базука, самонаводящаяся ракета, миномёт, граната, кассета, банан, святая граната |
| Лучи и удары | дробовик, узи, кулак, бита |
| Закладки | динамит, мина, овца, супер-овца |
| По метке с неба | налёт, напалм, минный удар, наковальня, бетонный осёл |
| Передвижение | верёвка, телепорт, толчок, парашют, ранец |
| Порода | бур, лампа, балка |

Оружие выбирается по иконкам — сетка слотов внизу экрана, в углу слота
боезапас и цифра клавиши; иконки рисует кодом `UI/WeaponIcons.cs`. Выбранное
оружие объявляется вылетающей на середину экрана картинкой, как на Sega.
Снаряжение (верёвка, толчок, бур, лампа, балка) урона не наносит и ход не
заканчивает.

## Соперник-бот

Команда под ботом отличается ровно одним: у неё заполнен `Team.Controller`.
Ход разложен на фазы — подумать, подойти, навести, набрать силу, выстрелить;
прицел доводится за полсекунды, так что видно, как бот целится. Выстрел
выбирается перебором пар «угол и сила» в два прохода, траектория считается тем
же полуявным Эйлером, что и физика, а воронка оценивается формулой настоящего
взрыва: свои в минус вдвое дороже, попадание по себе — втрое.

| Сложность | Перебор | Разброс |
|---|---|---|
| Лёгкая | шаг 12°, без уточнения | ±5,5°, ±9 % силы |
| Обычная | 8°, уточнение 2° | ±1,8°, ±3,5 % |
| Трудная | 8°, уточнение 1,2° | ±0,5°, ±1,2 % |

## Проверка

Все тесты — пункты меню **Worms**, поэтому запускаются одинаково: руками из
редактора, через мост к открытому редактору или в batchmode без него.

| Что проверяем | Пункт меню |
|---|---|
| матч целиком | `Worms/Smoke test` |
| соперник-бот | `Worms/Тест бота` |
| звук, ящики, верёвка, телепорт, потоп | `Worms/Тест содержимого` |
| слой ввода | `Worms/Тест ввода` |
| управление касаниями | `Worms/Тест управления касаниями` |
| стейт-машина меню | `Worms/Тест меню` |
| пять типов мира | `Worms/World test` |
| мосты | `Worms/Мосты — аудит` |
| швы коллайдера, замер взрыва | `Worms/Terrain test`, `Worms/Terrain bench` |

Через мост к открытому редактору (`unity mcp`, порт 7800):

```bash
unity cmd menu --path "Worms/Smoke test" && unity cmd console --tail 40
```

Без редактора:

```bash
/Applications/Unity/Hub/Editor/6000.6.0b5/Unity.app/Contents/MacOS/Unity -batchmode -nographics -projectPath . -executeMethod SmokeTest.Run -logFile /tmp/smoke.log
```

Остальные прогоны и их разбор — в [docs/DESIGN.md](docs/DESIGN.md#проверка).

## Сборка

`Valera Games` / `Wormfall` / `com.valeragames.wormfall`, IL2CPP на всех
платформах. `Editor/BuildAll.cs` собирает по одной цели или все сразу.

```bash
/Applications/Unity/Hub/Editor/6000.6.0b5/Unity.app/Contents/MacOS/Unity -batchmode -nographics -projectPath . -executeMethod BuildAll.All -logFile /tmp/build.log
```

| Цель | Выход | Особенности |
|---|---|---|
| iOS | Xcode-проект | deployment target 15.0, `PrivacyInfo.xcprivacy` кладётся на постпроцессе |
| Android | `.aab` | `targetSdk 35`, только arm64 |
| Mac | `.app` | universal (`x86_64` + `arm64`) |
| Windows | `.exe` | собирается только с Windows-хоста |

Единственные ассеты проекта — `Assets/Resources/UiPanel.asset` и
`UnityDefaultRuntimeTheme.tss`, и они обязательны: без `PanelSettings` сборка
показывает серый экран при работающем звуке. Создаются заново меню
**Worms → Сборка → Создать ассеты интерфейса**.
